# نصب و استفاده از مهارت‌های عامل هوش مصنوعی (Agent Skills)

**Agent Skills** (استاندارد باز `SKILL.md` / `agentskills.io`) مجموعه‌ای از دستورالعمل‌های تخصصی، سناریوهای گام‌به‌گام و مرجع‌های دامنه‌ای هستند که به دستیارهای کدنویسی و تحلیل (مثل **Claude Code**، **Cursor**، **Codex** و **Antigravity**) می‌آموزند چطور با یک ابزار و دامنهٔ تخصصی به‌شکل درست کار کنند.

در `tehran-stocks` نسخهٔ ۳، دو مهارت تخصصی مستقیماً درون بستهٔ پایتون (wheel) و مخزن گیت‌هاب قرار دارند:

| نام مهارت | کاربرد اصلی | چه زمانی توسط ایجنت استفاده می‌شود؟ |
| :--- | :--- | :--- |
| **`tehran-stocks-setup`** | راهنمای نصب، پیکربندی MCP، راه‌اندازی پایگاه داده و مهاجرت از نسخهٔ ۲ | وقتی از ایجنت می‌خواهید پروژه، سرور MCP یا دیتابیس `tehran-stocks` را روی سیستم شما تنظیم یا عیب‌یابی کند |
| **`tehran-stocks-analysis`** | پلی‌بوک‌های تحلیل سهم، اسکرین بازار، تحلیل جلالی، مرجع API و واژه‌نامهٔ بورس تهران | وقتی از ایجنت می‌خواهید سهمی را تحلیل کند، اسکریپت بک‌تست بنویسد یا داده‌های بورس تهران را تفسیر کند (شامل قوانین ریال/تومان، حجم مبنا، تعدیل قیمت و صف خرید/فروش) |

!!! info "تفاوت MCP و Agent Skills چیست؟"
    - **سرور MCP** به ایجنت **دسترسی به داده** می‌دهد (می‌تواند قیمت، صف و کدال را زنده بخواند).
    - **Agent Skills** به ایجنت **دانش تخصصی و روش کار درست** را می‌دهد (می‌داند چطور کد پایتون نسخهٔ ۳ بنویسد، چرا باید `adjusted=True` بگذارد، چرا نباید `resample("ME")` میلادی را روی تاریخ شمسی بزند و چطور ریال را به تومان گزارش کند).
    - بهترین نتیجه از استفادهٔ **هم‌زمان** هر دو به دست می‌آید!

## روش ۱: نصب از طریق ابزار `npx skills` (مستقیم از گیت‌هاب)

اگر `Node.js` / `npx` دارید، بدون نیاز به نصب پایتون هم می‌توانید مهارت‌ها را مستقیم از مخزن گیت‌هاب نصب کنید:

```bash
# نصب هر دو مهارت در پروژهٔ فعلی
npx skills add ghodsizadeh/tehran-stocks

# نصب سراسری (-g) و انتخاب مشخص مهارت‌ها
npx skills add ghodsizadeh/tehran-stocks \
  --skill tehran-stocks-setup \
  --skill tehran-stocks-analysis \
  -g
```

## روش ۲: نصب از طریق خط فرمان داخلی پایتون (`tse skill`)

هر دو مهارت درون خود بستهٔ `tehran-stocks` قرار دارند، بنابراین حتی بدون `Node.js` (یا در محیط‌های آفلاین) می‌توانید با `tse skill` یا `uvx` آن‌ها را نصب کنید.

### بررسی مهارت‌های موجود

```bash
# مشاهدهٔ فهرست مهارت‌های داخل بسته
tse skill list

# مشاهدهٔ مسیر فیزیکی فایل‌های مهارت روی سیستم
tse skill path
```

### نصب خودکار در پروژه یا به‌صورت سراسری

```bash
# تشخیص خودکار ایجنت‌های موجود در پوشهٔ پروژهٔ فعلی و نصب مهارت‌ها
tse skill install --target auto --scope project

# یا اجرا بدون نصب دائمی بسته با uvx:
uvx --from tehran-stocks tse skill install --target auto --scope project
```

### نصب برای یک دستیار مشخص

می‌توانید دقیقاً مشخص کنید مهارت‌ها برای کدام ابزار و در سطح پروژه (`project`) یا سراسری (`global`) نصب شوند:

```bash
# نصب سراسری برای Claude Code
tse skill install --target claude --scope global

# نصب در پروژه برای Cursor
tse skill install --target cursor --scope project

# نصب سراسری برای Antigravity
tse skill install --target antigravity --scope global

# نصب فقط یکی از مهارت‌ها برای Codex
tse skill install --target codex --scope project --skill tehran-stocks-analysis
```

## مسیر نصب برای هر دستیار هوش مصنوعی

جدول زیر نشان می‌دهد هر گزینهٔ `--target` و `--scope` فایل‌های مهارت را در چه پوشه‌ای قرار می‌دهد:

| مقدار `--target` | در سطح پروژه (`--scope project`) | در سطح سراسری (`--scope global`) |
| :--- | :--- | :--- |
| `claude` | `./.claude/skills/` | `~/.claude/skills/` |
| `cursor` | `./.cursor/skills/` | `~/.cursor/skills/` |
| `codex` | `./.codex/skills/` | `~/.codex/skills/` |
| `antigravity` | `./.agents/skills/` | `~/.gemini/config/skills/` |
| `agents` *(مسیر استاندارد مشترک)* | `./.agents/skills/` | `~/.agents/skills/` |
| `auto` *(پیش‌فرض)* | تمام پوشه‌های ایجنتِ موجود در پروژه را شناسایی می‌کند (و اگر نبود در `.agents/skills/` می‌ریزد) | تمام پوشه‌های ایجنتِ موجود در `HOME` را شناسایی می‌کند |

!!! tip "سفارشی‌سازی پوشهٔ مقصد"
    با گزینهٔ `--dir /path/to/base` می‌توانید پوشهٔ مبنا را به‌دلخواه تغییر دهید.

## رفتار ایمن در برابر بازنویسی (`--overwrite`)

نصب‌کنندهٔ `tse skill install` به‌صورت پیش‌فرض **نسخه‌های قبلی مهارت‌ها را (چه پوشه باشند و چه سیم‌لینک ساخته‌شده توسط `npx skills`) دستکاری یا حذف نمی‌کند**. پیش از نوشتن هر فایلی همهٔ مسیرها را بررسی می‌کند و در صورت وجود نسخهٔ قبلی بدون تغییر خارج می‌شود.

زمانی که نسخهٔ جدید `tehran-stocks` را نصب کردید و می‌خواهید مهارت‌ها را به‌روز کنید، گزینهٔ `--overwrite` را اضافه کنید (جایگزینی به‌صورت مرحله‌ای و اتمیک انجام می‌شود تا هیچ‌وقت فایلی ناقص نماند):

```bash
tse skill install --target auto --scope project --overwrite
```

## پس از نصب چطور از مهارت‌ها استفاده کنم؟

نیاز به کار خاصی نیست! دستیارهای سازگار با استاندارد Agent Skills توضیحات (`SKILL.md`) مهارت‌ها را به‌صورت خودکار می‌خوانند و هر زمان درخواست شما به بورس تهران یا `tehran-stocks` مربوط باشد، مهارت مناسب را فعال می‌کنند.

چند مثال از درخواست‌هایی که مهارت‌ها را فعال می‌کنند:

- **فعال‌سازی `tehran-stocks-setup`:**
  > «بستهٔ `tehran-stocks` نسخهٔ ۳ را در این پروژه نصب کن و فایل تنظیمات MCP را برای اتصال به یک دیتابیس SQLite آماده کن.»

- **فعال‌سازی `tehran-stocks-analysis`:**
  > «یک اسکریپت پایتون با `tehran-stocks` بنویس که تاریخچهٔ تعدیل‌شدهٔ دو سالهٔ `فولاد` و `کگل` را بگیرد، کندل‌های ماهانهٔ شمسی بسازد و بازدهی هر ماه شمسی را مقایسه کند.»

  > «کد قدیمی من که از `tehran-stocks` نسخهٔ ۲ و `Stocks.query` استفاده می‌کرد را به نسخهٔ ۳ و `Client` جدید تبدیل کن.»
