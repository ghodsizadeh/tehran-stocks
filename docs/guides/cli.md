# سناریو ۵: کار سریع در ترمینال با خط فرمان `tse`

گاهی فقط می‌خواهید بدون باز کردن Jupyter یا نوشتن اسکریپت پایتون، در چند ثانیه وضعیت بازار را چک کنید، یک فایل `CSV` برای اکسل بگیرید یا خروجی `JSON` را به ابزارهایی مثل `jq` بدهید.

فرمان **`tse`** (و نام مستعار آن **`tehran-stocks`**) دقیقاً برای همین سناریوها طراحی شده است و **هیچ‌یک از فرمان‌های بازار آن به پایگاه داده نیاز ندارد**.

---

## سناریوی ۱: چک‌لیست صبحگاهی و رصد کلی بازار

```bash
# وضعیت کلی بورس تهران (شاخص کل، هم‌وزن، ارزش معاملات)
tse market

# وضعیت بازار فرابورس (flow=2)
tse market --flow 2

# فهرست شاخص‌های بازار و صنایع
tse indices

# تاریخچهٔ شاخص کل (TEDPIX)
tse indices --history TEDPIX --limit 15

# صنایع برتر بر اساس ارزش معاملات
tse sectors --limit 15
```

---

## سناریوی ۲: بررسی فوری یک نماد در ترمینال

تمام فرمان‌ها نماد فارسی/عربی (`کگل` یا `كگل`)، شناسهٔ ISIN و `insCode` را می‌پذیرند:

```bash
# جست‌وجوی نماد وقتی اسم دقیق را نمی‌دانید
tse search "گل گهر"

# قیمت لحظه‌ای، پایانی، حجم و درصد تغییر
tse quote کگل

# جریان پول حقیقی/حقوقی امروز
tse client-type کگل

# سابقهٔ ۱۰ روزهٔ جریان پول حقیقی/حقوقی
tse client-type کگل --history --days 10

# ۵ سطر سفارش همراه با تشخیص صف خرید/فروش
tse orderbook کگل --thresholds

# بنیاد، EPS، P/E گروه و آمارهای تکمیلی
tse info کگل --stats --identity

# بررسی حباب NAV برای یک صندوق ETF
tse info بمان --etf

# سهامداران عمده، سود/افزایش سرمایه، کدال و پیام ناظر
tse shareholders کگل
tse dividends کگل --share-changes
tse codal کگل --limit 5
tse messages کگل --limit 5
```

---

## سناریوی ۳: فیلترنویسی فوری روی کل بازار (`tse screen`)

با `tse screen` می‌توانید کل بازار را بر اساس ارزش معاملات (`value`)، حجم (`volume`)، درصد تغییر (`change`)، ورود پول حقیقی (`money_flow`) یا قدرت خریدار (`buyer_power`) مرتب و فیلتر کنید:

```bash
# ۱۵ نماد برتر از نظر ورود پول حقیقی
tse screen --sort money_flow --limit 15

# ۲۰ نماد با بیشترین قدرت خریدار حقیقی
tse screen --sort buyer_power --limit 20

# فیلتر داخل یک صنعت مشخص (مثلاً گروه خودرو با کد 34) همراه با ستون‌های پول حقیقی
tse screen --sector 34 --with-flow --sort value --limit 10

# دیدن نمادهایی که بیشترین افت یا خروج پول را داشته‌اند (--asc برای مرتب‌سازی صعودی)
tse screen --sort money_flow --asc --limit 10
```

---

## سناریوی ۴: خروجی گرفتن برای اکسل (`CSV`) و اسکریپت‌نویسی (`JSON`)

تمام فرمان‌های داده به‌طور پیش‌فرض جدول خوانا نمایش می‌دهند، اما با `--format csv` یا `--json` بلافاصله آمادهٔ ذخیره در فایل یا ترکیب با ابزارهای خط فرمان می‌شوند:

```bash
# دریافت تاریخچهٔ تعدیل‌شدهٔ یک سهم با تاریخ شمسی در فایل CSV
tse history کگل --days 120 --adjusted --format csv > kgl_120d.csv

# دریافت تاریخچه در یک بازهٔ شمسی مشخص
tse history فولاد --start 1403-01-01 --end 1403-06-31 --adjusted --format csv > foolad_h1_1403.csv

# استخراج آخرین قیمت و درصد تغییر با jq در اسکریپت‌های شل
tse quote کگل --json | jq '{last, close, change_pct, volume}'

# ذخیرهٔ خروجی فیلتر بازار در JSON
tse screen --sort money_flow --limit 25 --json > top_inflows.json
```

## سناریوی ۵: کار با پایگاه دادهٔ محلی از ترمینال

اگر می‌خواهید یک فایل SQLite بسازید و هر شب آن را به‌صورت افزایشی به‌روز کنید:

```bash
# ۱. ایجاد پایگاه داده
tse db init --db ./tse.sqlite

# ۲. همگام‌سازی نمادهای منتخب همراه با حقیقی/حقوقی
tse db sync --db ./tse.sqlite --symbols کگل,فولاد,شپنا --client-type

# ۳. بررسی تعداد ردیف‌ها و تاریخ آخرین به‌روزرسانی
tse db status --db ./tse.sqlite

# ۴. اجرای پرس‌وجوی SQL فقط‌خواندنی
tse db query --db ./tse.sqlite \
  "SELECT ins_code, date, close, volume FROM daily_prices ORDER BY date DESC LIMIT 5" --json
```

## نکات کاربردی: اجرا بدون نصب، پروکسی و کدهای خطا

- **اجرا بدون نصب دائمی:** هر فرمانی را می‌توانید با `uvx --from tehran-stocks tse ...` اجرا کنید.
- **پروکسی و زمان انتظار:** از گزینه‌های سراسری `--timeout` و `--proxy` یا متغیرهای محیطی `TEHRAN_STOCKS_TIMEOUT` و `TEHRAN_STOCKS_PROXY` استفاده کنید:
  ```bash
  tse --timeout 30 --proxy http://127.0.0.1:8080 market
  ```
- **کدهای خروج (Exit Codes) برای اسکریپت‌نویسی:** خطاها تمیز روی `stderr` چاپ می‌شوند و کد خروج مشخص برمی‌گردانند (`2` خطای ورودی، `3` نماد یافت نشد، `4` محدودیت نرخ، `5` خطای TSETMC و `6` خطای پایگاه داده).
