# بورس تهران در پایتون (`tehran-stocks` نسخهٔ ۳)

**`tehran-stocks` نسخهٔ ۳** یک ابزار مدرن، سریع و آماده برای پایتون، ترمینال و دستیارهای هوش مصنوعی است که داده‌های بورس و فرابورس تهران را مستقیماً از رابط JSON رسمی شرکت مدیریت فناوری بورس تهران (`cdn.tsetmc.com`) دریافت می‌کند.

برخلاف نسخه‌های قدیمی، وارد کردن (`import`) این کتابخانه در پایتون **هیچ فایل تنظیماتی نمی‌سازد، هیچ پایگاه داده‌ای ایجاد نمی‌کند و هیچ پرسشی از کاربر نمی‌پرسد**. هر زمان که به داده نیاز دارید آن را لحظه‌ای دریافت می‌کنید و فقط در صورت نیاز واقعی (مثل بک‌تست چندساله یا گزارش‌گیری آفلاین) پایگاه دادهٔ محلی را فعال می‌کنید.

## تجربهٔ ۶۰ ثانیه‌ای

اگر می‌خواهید همین الان حس کار با نسخهٔ ۳ را ببینید، این دو مثال کوتاه بدون هیچ پیش‌نیاز پایگاه داده‌ای کار می‌کنند:

=== "در پایتون"

    ```python
    import tehran_stocks as ts

    with ts.Client() as client:
        quote = client.prices.quote("کگل")
        flow = client.client_type.live("کگل")
        bars = client.prices.history("کگل", days=30, adjusted=True)

    print(f"آخرین معامله: {quote.last:,.0f} ریال | پایانی: {quote.close:,.0f} ریال")
    print(f"قدرت خریدار حقیقی: {flow.buyer_power:.2f}")

    df = ts.to_dataframe(bars, jalali=True, index_by_date=True)
    print(df[["open", "high", "low", "close", "volume"]].tail())
    ```

=== "در ترمینال (بدون نیاز به نصب با uvx)"

    ```bash
    # مشاهدهٔ وضعیت کلی بازار و شاخص کل
    uvx --from tehran-stocks tse market

    # دریافت قیمت و وضعیت سهم کگل
    uvx --from tehran-stocks tse quote کگل

    # پیدا کردن ۱۰ سهم برتر بازار از نظر ورود پول حقیقی
    uvx --from tehran-stocks tse screen --sort money_flow --limit 10
    ```

=== "برای دستیار هوش مصنوعی (MCP)"

    ```json
    {
      "mcpServers": {
        "tehran-stocks": {
          "command": "uvx",
          "args": ["--from", "tehran-stocks", "tse", "mcp"]
        }
      }
    }
    ```

## چرا نسخهٔ ۳ متفاوت است؟

- **بدون اثر جانبی (On-demand First):** تا زمانی که خودتان نخواهید، نه دیتابیسی ساخته می‌شود و نه پوشه‌ای در سیستم شما تغییر می‌کند.
- **سازگار با حروف فارسی و عربی:** چه بنویسید `کگل` و چه `كگل`، یا شناسهٔ `ISIN` و یا `insCode` وارد کنید، کتابخانه به‌طور خودکار آن را یکسان‌سازی و پیدا می‌کند.
- **تعدیل خودکار قیمت‌ها:** با یک گزینهٔ `adjusted=True` تمام افت‌های ناشی از مجمع و افزایش سرمایه به‌صورت پس‌رو (Backward) تعدیل می‌شوند.
- **پشتیبانی بومی از تقویم جلالی:** تبدیل مستقیم خروجی‌ها به `DataFrame` با شاخص `JalaliDatetimeIndex` و سازگاری کامل با `jalali-pandas>=1.0.0`.
- **آماده برای عصر هوش مصنوعی:** سرور رسمی `MCP` (نسخهٔ `mcp>=2.0`) و مهارت‌های استاندارد `Agent Skills` درون خود بسته گنجانده شده‌اند.

!!! tip "از نسخهٔ ۲ مهاجرت می‌کنید؟"
    نسخهٔ ۳ بازطراحی کامل پروژه است و با رابط قدیمی `Stocks` و فرمان `ts-get` سازگار نیست. برای تبدیل سریع کدهای قدیمی، [راهنمای مهاجرت از نسخهٔ ۲ به ۳](concepts/migration-v2-to-v3.md) را ببینید.
